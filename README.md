# Customer Churn Prediction

## Project Overview
This project predicts whether a telecom customer
will leave the company using Machine Learning.

## Dataset
- Training Data: 2666 records
- Testing Data: 667 records
- Total Features: 19
- Target Variable: Churn

## Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Joblib

## Machine Learning Algorithms
1. Random Forest Classifier
2. Logistic Regression

## Model Evaluation
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC Score

## Final Model
Random Forest Classifier with
a 0.30 prediction threshold.

## Project Files
- Churn_Prediction.ipynb
- churn-bigml-80.csv
- churn-bigml-20.csv
- customer_churn_final_model.pkl
- requirements.txt

## Conclusion
The project uses Machine Learning to identify
customers who may leave a telecom service.
It helps understand customer churn patterns
and supports customer retention decisions.
